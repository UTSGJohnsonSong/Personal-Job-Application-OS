# User Flows

## Onboarding
1. Create account (single principal) → optional MFA.
2. Import resume(s) / LinkedIn export / GitHub / portfolio.
3. Review extracted Personal Context; **confirm** each fact (sets
   `can_use_for_application`). Nothing unconfirmed enters applications.
4. Set preferences (locations, remote, comp, industries, dealbreakers).
5. Add target companies / sources.

## Daily loop
1. Dashboard shows overview metrics, action items, funnel, time views.
2. Job Inbox: review New / Strong Match / Apply / Manual Review / Uncertain; filter,
   sort, batch-mark, batch-build packets, batch re-verify open.
3. Job Detail: eligibility (with evidence), ranking breakdown, risks, deadline.
4. Build Application Packet: system selects resume, tailors (truthfully), drafts
   answers/cover letter with provenance; user reviews.
5. Browser assist fills the official form (Level 2).
6. **Confirm and Submit** per job (Level 3) → tracker records submission.

## Ongoing
- Tracker timeline per application; email-driven status updates (with confidence;
  low confidence asks the user).
- Reminders for deadlines, assessments, stale (>2w) applications, interviews.
- Learning surfaces periodic insights and (opt-in) weight suggestions.

## Data control
- Personal Context page: see/edit/delete/restrict/export/revoke; per-application
  "what data was used" trace via audit log.
